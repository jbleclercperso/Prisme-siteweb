Cacher ses vidéos porno sur son PC : ce qui protège vraiment

Un PC partagé, un proche qui emprunte l'ordinateur, quelqu'un qui entre dans la pièce au mauvais moment : il y a deux problèmes différents. Que personne ne tombe sur votre collection, et que personne ne puisse la trouver en cherchant. Voici ce qui marche pour chacun, des réglages gratuits de Windows au chiffrement.

En bref

Un dossier « caché » de Windows ne cache rien à qui cherche. Pour une vraie protection, un compte Windows à vous, protégé par mot de passe, et pour les fichiers eux-mêmes, le chiffrement : BitLocker, ou un coffre VeraCrypt, gratuit.

Pour ne pas être surpris pendant qu'on regarde, il faut un geste qui fait tout disparaître instantanément. Prisme en a un : Ctrl+K remplace tout par un écran banal et animé, et seul un code PIN fait revenir la collection.

Ce qui ne protège pas

  • L'attribut « caché » : il suffit de cocher « Éléments masqués » dans l'Explorateur pour tout revoir.
  • Un dossier au nom anodin (« Pilotes », « Sauvegarde 2019 ») : il ne résiste pas à une recherche, ni aux vignettes de l'Explorateur.
  • Une archive zip « protégée » qu'on décompresse pour regarder : les fichiers décompressés restent sur le disque.

Les traces qu'on oublie

  • Les fichiers récents : l'accueil de l'Explorateur et le menu Démarrer montrent ce qu'on a ouvert. Décochez « Afficher les fichiers récemment utilisés » dans les options de l'Explorateur, et désactivez les éléments récents dans Paramètres › Personnalisation › Démarrer.
  • La synchronisation : un dossier placé dans OneDrive, Google Drive ou Dropbox part sur leurs serveurs et sur vos autres appareils. Gardez la collection hors des dossiers synchronisés.
  • L'application Photos de Windows rassemble les images des dossiers Images et Vidéos : rangez la collection ailleurs.
  • Le lecteur : beaucoup de lecteurs gardent une liste des derniers fichiers lus. VLC la vide dans Outils › Préférences, en décochant « Sauvegarder les éléments récents ».

Ce qui protège vraiment

  1. Un compte Windows à vous, avec un mot de passe ou un code. Les autres utilisateurs du PC n'ont pas accès à vos dossiers personnels. C'est simple, gratuit, et suffisant dans la plupart des foyers.
  2. Le chiffrement du disque : BitLocker (Windows Pro) ou le chiffrement de l'appareil (beaucoup de PC sous Windows Famille) protège tout le disque si le PC est volé ou démonté.
  3. Un coffre chiffré : VeraCrypt, libre et gratuit, crée un fichier-coffre qui s'ouvre comme un disque avec un mot de passe, et redevient illisible une fois fermé. C'est la protection la plus forte pour une collection précise.

Ce que fait Prisme

Prisme est un logiciel Windows pour trier, organiser et regarder une collection de vidéos pour adultes, conçu pour qu'on puisse s'en servir sans crainte :

  • Le geste qui fait tout disparaître : Ctrl+K (ou la lune de l'en-tête) cache Prisme et toutes ses fenêtres derrière un écran banal. Il a été choisi parmi cinq, qui bougent comme les vrais : Windows Update, un tableur, une copie de fichiers, un document qui s'écrit, le Gestionnaire des tâches. Depuis n'importe quelle autre fenêtre, Ctrl+Alt+K fait la même chose.
  • Un retour qui ne se fait pas par réflexe : on sort de l'écran de repli par Ctrl+K ou un double-clic, pas par Échap, la touche qu'un curieux essaierait.
  • Un code PIN de quatre chiffres, demandé à l'ouverture de Prisme (sous un titre et une icône neutres, avant que rien de la collection n'apparaisse), au retour de l'écran de repli, et pour afficher les dossiers masqués. Après cinq erreurs, il faut attendre, de plus en plus longtemps.
  • Des dossiers masqués : ils disparaissent de tout Prisme, Mur et accès à distance compris. Sur le disque, rien ne bouge ; un geste, avec le code, les fait revenir.
  • 100 % local : aucun compte, aucune télémétrie, rien n'est envoyé. Vos favoris, mots-clés et index vivent dans le dossier de données de Prisme, pas dans vos dossiers.
  • Un lecteur intégré : les vidéos se regardent dans Prisme, sans laisser de liste de fichiers récents dans un autre lecteur.
Ce que Prisme ne fait pas
  • Il ne chiffre pas vos fichiers. Quelqu'un qui ouvre vos dossiers dans l'Explorateur les voit. Pour cela : un compte Windows à vous, BitLocker ou VeraCrypt, qui fonctionnent très bien avec Prisme.
  • Les vignettes que Prisme prépare sont gardées dans son dossier de données, sur le PC : elles sont protégées par votre compte Windows, pas par le code PIN.

Questions fréquentes

Comment cacher un dossier sur Windows 11 ?

Clic droit › Propriétés › cocher « Caché » : le dossier disparaît de l'Explorateur, mais réapparaît dès qu'on affiche les éléments masqués. Pour une vraie protection, un compte Windows à vous, ou un coffre chiffré VeraCrypt.

Comment protéger un dossier par mot de passe ?

Windows ne le propose pas directement. La solution la plus sûre est un coffre VeraCrypt (gratuit) : un fichier qui s'ouvre comme un disque avec un mot de passe. BitLocker, sur Windows Pro, chiffre un disque entier ou une clé.

Existe-t-il un bouton panique pour cacher une fenêtre d'un coup ?

Windows a Win+D, qui montre le bureau, mais un clic ramène tout. Prisme a un vrai écran de repli : Ctrl+K, ou Ctrl+Alt+K depuis n'importe quelle fenêtre, et un code PIN pour revenir.

Prisme envoie-t-il quelque chose sur Internet ?

Non. Prisme est entièrement local, sans compte ni télémétrie. Le partage vers le téléphone ne s'ouvre que si vous l'activez, protégé par un mot de passe.
